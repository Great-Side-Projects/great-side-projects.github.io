References and data sources

Metric formulas (this app)

  • Lead Time = merged_at − created_at (time from PR open to merge, in hours).
  • TTFR = first_review_at − created_at (time to first review, from reviews.nodes[0].submittedAt).
  • Review cycles = 1 + count(CHANGES_REQUESTED) per PR; we use the median.
  • PR size = additions + deletions (buckets: XS 0–9, S 10–29, M 30–99, L 100–499, XL+ 500+).

Data extraction (this app)

  • GraphQL API (v4): repository.pullRequests (states: MERGED, first 100, orderBy UPDATED_AT). Fields: createdAt, mergedAt, additions, deletions, author.login, reviews.first(25) (submittedAt, state, author.login). Used for org/repo metrics and for the Contributors module (per-author and per-reviewer stats). One request per repo.
  • REST API: GitHub REST API — GET /orgs/:org/repos (per_page=100) for the repo list; GET /repos/:owner/:repo/pulls?state=open&per_page=1 (Link header) for open PR count; GET /repos/.../commits?per_page=1 for last commit.
  • Auth: Personal Access Token with repo scope (and read:org for private orgs). SSO authorization required if the org enforces it.
  • Metrics not from GitHub: Cycle Time (first commit→deploy) and Change Failure Rate are not provided by GitHub APIs; we show “Data not available” where applicable.
